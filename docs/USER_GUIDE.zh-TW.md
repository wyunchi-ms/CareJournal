# 病程記 CareJournal 使用手冊

[文件首頁](README.md) · [简体中文](USER_GUIDE.zh-CN.md) · 繁體中文 · [English](USER_GUIDE.en.md)

> 本手冊描述目前倉庫功能；已安裝版本的差異請查看[更新記錄](../ChangeLog.md)。本軟體只用於記錄、整理及視覺化資料，不提供診斷、治療建議或風險預測。

## 1. 首次開啟：地區與語言

第一次開啟，以及從舊版本升級後第一次開啟時，請選擇**地區**和**語言**。

- 地區決定 OCR 整理檢查報告時採用的常用臨床單位。
- 語言用於首次引導、主導覽和 OCR 的自然語言欄位。
- 可在「設定 → 地區與語言」隨時修改。
- 選擇「其他地區」時，OCR 會保留原始報告單位，不會進行不可靠的換算。

可選地區包括中國大陸、香港、澳門、台灣、新加坡、美國、英國、加拿大、澳洲及其他地區；可選語言包括簡體中文、繁體中文及英語。

## 2. 安裝與資料儲存

請從 [GitHub Releases](https://github.com/wyunchi-ms/CareJournal/releases) 或 [Gitee 鏡像](https://gitee.com/wyunchi/care-journal/releases) 下載 Android APK，或將 Windows x64 ZIP 解壓縮到可寫入目錄後執行 `CareJournal.exe`。升級時直接覆蓋安裝，不要先解除安裝，以免刪除本機資料。Android 使用本機 SQLite 和應用程式私有儲存；Windows 綠色版將資料存放在 EXE 同層的 `CareJournalData/`。

Windows 搬移資料前請關閉程式，將 EXE 與 `CareJournalData/` 一起複製。HarmonyOS 需要[自行建置與裝置簽署](HARMONY_SELF_BUILD.zh-CN.md)（簡體中文）；iOS 仍為[尚未驗證的開發候選](IOS_NATIVE.md)（簡體中文）。

## 3. 病程與治療方案

在**病程**可建立手術、住院、化療、放療、維持治療、標靶、免疫、用藥、檢查、身體指標或日記事件。

在**方案**可建立可重複使用的治療方案，設定週期、治療日、藥物、劑量、單位與給藥途徑。選擇方案與 Day 1 後可批量建立後續治療日；每一筆生成事件仍可個別修改。

## 4. 檢查報告與 OCR

在**檢查 → 匯入報告**可拍照、選取圖片/PDF，或在 Android 批量匯入資料夾。OCR 會在背景佇列執行，失敗時可重試。

辨識完成後會建立報告類型、採樣日期、醫院、結構化指標、異常標記與原始素材。OCR 會將數值、參考範圍與單位視為一組；對已設定地區，應用程式會要求模型同步換算數值、參考範圍與單位，但不能保證每次辨識都正確。請一律與原始報告核對。

### 隱私選項

開啟 PaddleOCR 本機去識別後，應用程式會先在裝置上擷取文字，並嘗試移除姓名、身分證號、住院號與電話，再將文字傳給你設定的 LLM。自動去識別可能有遺漏，重要資料請自行複核。

## 5. 圖表與報銷

在**圖表**可查看依日期的檢驗指標與身體指標趨勢，以及以 Day 1 對齊的治療週期比較，並儲存常用圖表設定。

在**報銷**可由相關治療事件建立報銷計畫，整理報告、收據等材料並標記完成狀態。

## 6. 智慧辨識服務

在**設定 → 智慧辨識服務**選擇服務商，填寫 API Key、API 位址和模型，再使用「測試連線」確認。API Key 只保存在目前裝置，不會加入區網同步或備份。直接辨識圖片需要模型支援圖片輸入；服務商可能按用量收費。

Azure OpenAI 使用 v1 API，例如 `https://<resource>.openai.azure.com/openai/v1` 或 `https://<resource>.services.ai.azure.com/openai/v1`。模型填寫 Deployment Name，無需 API Version。

## 7. 區域網路同步

在可信任的 Wi-Fi 下，兩台裝置都開啟區網同步，選擇發現的裝置、查看同步預覽、選擇資料類別後再確認。傳輸不經過維護者伺服器，但目前沒有額外的應用層加密；請勿在公共 Wi-Fi 或未知裝置上使用。LLM 設定與 OCR 佇列不會同步。

## 8. 備份與還原

使用**設定 → 備份與還原**匯出 ZIP；內容包含 `backup.json` 與去重後的圖片/PDF 素材。ZIP 未加密，請只存放在可信任位置。API Key 和本機檔案路徑不會寫入備份。匯入時會先顯示確認，確認後才覆蓋目前裝置資料。

舊版 AES-GCM 加密備份仍可匯入；選取加密備份後，應用程式才會要求輸入原本的密碼。

## 9. 重要限制

- 本應用不是醫療器材或緊急服務。
- OCR 與本機去識別可能不完整或不正確。
- 請保留原始資料，並向醫療團隊確認重要資訊。
- 不要在公開專案管道分享病歷、API Key 或其他個人資料。

## 10. 常見問題

- **OCR 暫停：** 切換應用程式內頁面不會停止佇列；系統終止應用程式後，未完成工作會在下次開啟時繼續。
- **找不到裝置：** 確認兩端連接同一 Wi-Fi、皆開啟同步，並檢查路由器用戶端隔離或防火牆限制。
- **Android 無法覆蓋安裝：** 確認新舊安裝套件來自相同簽署來源；考慮解除安裝前，請先匯出備份。
