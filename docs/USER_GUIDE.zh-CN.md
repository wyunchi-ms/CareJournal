# 病程记 CareJournal 用户手册

[文档首页](README.md) · 简体中文 · [繁體中文](USER_GUIDE.zh-TW.md) · [English](USER_GUIDE.en.md)

> 本手册描述当前仓库功能；已安装版本的差异请查看 [更新记录](../ChangeLog.md)。
> 本软件只用于记录、整理和可视化，不提供诊断、治疗建议或风险预测。

## 1. 软件简介

病程记面向肿瘤患者及家属，用于集中管理：

- 手术、住院、化疗、放疗、靶向、免疫、维持治疗和日常用药；
- 检查报告、原始图片/PDF 和结构化指标；
- 指标趋势图与化疗周期对比图；
- 报销计划与材料清单；
- 本地 ZIP 备份和局域网设备同步；
- 使用自有 LLM 服务进行报告 OCR 和结构化识别。

数据默认保存在设备本地。Android 使用 SQLite，HarmonyOS 使用 ArkData RDB，Windows 将 WebView2 本地数据库和素材保存在程序旁的 `CareJournalData/`。

## 2. 安装与首次使用

下载入口：[GitHub Releases](https://github.com/wyunchi-ms/CareJournal/releases) · [Gitee 镜像](https://gitee.com/wyunchi/care-journal/releases)。公开安装包为 Android APK 和 Windows ZIP；iOS 尚未完成 Mac 编译和真机验证，见 [iOS 状态](IOS_NATIVE.md)。

### Android

1. 从 GitHub 或 Gitee Release 下载 `carejournal-vX.Y.Z-android.apk`。
2. Android 提示时允许“安装未知应用”。
3. 覆盖安装升级时不要卸载旧版本，否则应用本地数据可能被删除。

### HarmonyOS NEXT

HarmonyOS NEXT 不支持像 Android APK 一样让未知用户下载 HAP 后直接安装，因此公开 Release 不再提供 Harmony 安装包。愿意使用 Windows 电脑自行安装的用户，请按 [HarmonyOS NEXT 自行构建与安装指南](HARMONY_SELF_BUILD.zh-CN.md)操作：安装 DevEco Studio、登录已实名认证的个人开发者账号，为自己的设备生成调试签名并运行。

### Windows 绿色桌面版

从 Release 下载 Windows x64 ZIP，解压后运行 `CareJournal.exe`，无需安装 Node.js 或部署公共 Web 服务。数据保存在 EXE 同级的 `CareJournalData/`；详细说明见[Windows 绿色桌面版说明](WINDOWS_DESKTOP.md)。

### 首次打开：地区与语言

第一次打开（或从旧版本升级后首次打开）时，请选择常用的**地区**和**语言**。地区和语言相互独立：

- 地区用于决定 OCR 整理检查报告时采用的常用临床单位；
- 语言用于首次引导、主导航和 OCR 中自然语言字段的显示语言；
- 可在“设置 → 地区与语言”随时修改；选择“其他地区”时，OCR 会保留报告原单位，避免不可靠的自动换算。

当前可选地区包括中国大陆、香港、澳门、台湾、新加坡、美国、英国、加拿大、澳大利亚和其他地区；可选语言包括简体中文、繁体中文和英语。

## 3. 病程日历

导航：**病程**。

![病程日历，使用虚构示例数据](images/calendar.png)

*截图来自桌面尺寸开发预览，使用虚构数据。*

### 新建病程

1. 点击右上角“+”。
2. 选择事件类型：手术、住院、化疗、放疗、维持治疗、靶向、免疫、用药、检查、身体指标或日记等。
3. 填写日期、医院、科室和备注。
4. 治疗事件可选择治疗方案，按周期批量生成多个治疗日。
5. 保存后事件会显示在月历和当天列表中。

### 按方案创建治疗事件

导航：**方案** → 新建/编辑方案。

- 支持化疗、放疗、维持、靶向、免疫等方案类型；
- 可配置周期长度、治疗日、药物、剂量、单位和给药途径；
- 放疗方案填写治疗部位和单次 Gy 剂量；
- 创建病程时选择方案和 Day 1，可批量生成后续治疗日；
- 生成后的单条事件仍可按实际执行情况修改。

## 4. 检查报告与 OCR

导航：**检查** → **导入报告**。

支持：

- 拍照导入；
- 选择图片或 PDF；
- Android 文件夹批量导入；
- OCR 队列后台处理、失败重试和批量清理。

识别成功后，报告会生成检查记录，包括：报告类型、采样日期、医院、结构化指标、异常标记和原始素材。

### 隐私注意

- 未开启本地脱敏时，图片可能发送到你配置的 LLM 服务商；
- 开启 PaddleOCR 本地脱敏后，应用会先提取文字并尝试删除姓名、身份证号、住院号和电话等；
- 自动脱敏可能有遗漏，重要材料必须人工复核；
- PDF 文字版会优先在本地提取文字。

## 5. 检查记录

导航：**检查**。

- 按报告类型和日期筛选；
- 查看原始图片/PDF 和指标表格；
- 编辑医院、日期、指标和异常状态；
- 将检查记录关联到病程事件；
- 使用 SHA-256 和视觉指纹减少重复素材。

## 6. 指标图表

导航：**图表**。

### 日期趋势

- 选择一个或多个检验指标，或已录入的身高、体重、体温、血压、心率、血氧等身体指标；
- 查看随日期变化的折线；
- 可显示治疗事件标记；
- 可收藏常用图表并排序。

### 化疗周期对齐

- 先在病程中创建带 Day 1 的治疗周期；
- 图表将多个周期按 Day 1 对齐；
- 便于比较不同周期同一天数的指标变化。

打开已收藏图表的详情后，下方来源列表每行只显示日期和当前指标的数值，点击可打开对应报告或身体记录。报告结果高于参考上限时标红并显示上箭头，低于参考下限时标绿并显示下箭头，正常时不显示箭头；不重复显示报告名、医院、指标名、单位或数量。缺少参考范围时沿用报告已有状态，未知状态不显示箭头；危急结果保留红色警示，读屏可读取完整状态。

## 7. 报销材料

导航：**报销**。

1. 选择相关治疗事件创建报销计划。
2. 选择医保、商保、自费等类型。
3. 按材料清单上传报告、发票等附件。
4. 标记完成状态。
5. 可批量选择计划并导出 ZIP。

## 8. 智能识别服务

导航：**设置** → **智能识别服务**。

1. 选择 Azure OpenAI、OpenAI、DeepSeek、月之暗面 Kimi、火山方舟、阿里云百炼、硅基流动、腾讯混元、阶跃星辰、百川智能、讯飞星火、Gemini、MiniMax 稀宇科技、智谱 GLM、OpenRouter 或自定义 OpenAI-compatible 服务。
2. 填写 API Key、API 地址和模型。
3. 使用“测试连接”确认配置。
4. 需要时开启 PaddleOCR 本地脱敏。

API Key 只保存在当前设备，不参与局域网同步或备份迁移。每个服务商保存一组配置，切换后会保留此前填写的内容。直接识别图片需要模型支持图片输入；服务商可能按用量收费。

Azure OpenAI 使用 v1 API：API 地址填写 `https://<resource>.services.ai.azure.com/openai/v1` 或 `https://<resource>.openai.azure.com/openai/v1`，模型填写 Deployment Name，无需 API Version。

### 地区单位规则

OCR 会将结果值、参考范围和单位作为一组处理。对于已配置地区，应用会要求模型使用该地区的常用临床单位，同时换算数值和参考范围；这是发送给模型的要求，不能保证每次识别都正确。不同地区常见体系不同，例如台湾与美国常见 g/dL、mg/dL 和 10³/μL，而英国、加拿大和澳大利亚多使用 SI 单位。请在导入后核对原始报告和结构化结果。

## 9. 局域网同步

导航：**设置** → **局域网同步**。

1. 两台设备连接同一 Wi-Fi。
2. 两边都开启局域网同步。
3. 点击发现的设备，应用会自动计算同步预览。
4. 查看“本机将发生”和“对方将发生”的变化。
5. 可取消某一类别，跳过该类别的本次同步。
6. 确认后依次执行数据交换、数据库合并、素材分块传输和目录整理。

同步完成后会显示变化条数、发送/接收素材数量和耗时。

注意：

- LLM 配置和 OCR 队列不会同步；
- 当前局域网同步不经过开发者服务器，但应用层不额外加密，请只在可信 Wi-Fi 下使用；
- 设备没有账号认证，请只选择认识的设备；
- 公共 Wi-Fi 或开启客户端隔离的网络可能无法发现设备；
- 素材传输中断后，下次同步会自动补齐未完成部分。

## 10. 备份、恢复与数据清理

- 在“设置 → 备份与恢复”导出 ZIP 完整备份；
- ZIP 中包含 `backup.json` 和去重后的图片/PDF 素材，不需要密码且不加密，请只保存在可信位置；
- LLM API Key 和本机文件路径不会写入备份；
- 导入后会先显示记录与素材数量，只有确认后才覆盖当前设备数据；
- 旧版 AES-GCM 加密备份仍可导入，选择旧文件后才会要求输入当时的备份密码；
- Android 可通过系统设置清除应用数据；Windows 绿色版需退出程序后删除对应的 `CareJournalData/` 目录。清理前先确认已有可用备份。

## 11. 常见问题

### 为什么 OCR 停止了？

切换应用内页面不会停止队列；系统终止应用后任务会暂停，下次打开应用时从未完成项继续。保持应用打开有助于完成批量识别。

### 为什么发现不到另一台设备？

确认两端在同一 Wi-Fi、都已开启同步，且路由器没有开启 AP/客户端隔离。

### 为什么覆盖安装失败？

先确认新旧安装包来自同一发布渠道。不同签名的 Android 安装包不能覆盖安装，例如自行构建的调试版与正式版。不要为解决安装问题直接卸载旧版；先导出备份，再根据错误提示反馈版本和安装包来源。

### 数据是否会上传到开发者服务器？

不会。应用没有账号、广告或开发者运营的云端病历服务。只有你主动执行 OCR 或局域网同步时，数据才按你选择的服务流转。
