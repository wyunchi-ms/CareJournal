# 病程记 CareJournal 用户手册

> 适用版本：0.19.17 及以后  
> 本软件只用于记录、整理和可视化，不提供诊断、治疗建议或风险预测。

## 1. 软件简介

病程记面向肿瘤患者及家属，用于集中管理：

- 手术、住院、化疗、放疗、靶向、免疫、维持治疗和日常用药；
- 检查报告、原始图片/PDF 和结构化指标；
- 指标趋势图与化疗周期对比图；
- 报销计划与材料清单；
- 本地加密备份和局域网设备同步；
- 使用自有 LLM 服务进行报告 OCR 和结构化识别。

数据默认保存在设备本地。Android 使用 SQLite，HarmonyOS 使用 ArkData RDB，Web 使用浏览器 IndexedDB。

## 2. 安装与首次使用

### Android

1. 从 GitHub 或 Gitee Release 下载 `carejournal-vX.Y.Z-android.apk`。
2. Android 提示时允许“安装未知应用”。
3. 覆盖安装升级时不要卸载旧版本，否则应用本地数据可能被删除。

### HarmonyOS NEXT

HarmonyOS NEXT 不支持像 Android APK 一样让未知用户下载 HAP 后直接安装，因此公开 Release 不再提供 Harmony 安装包。愿意使用 Windows 电脑自行安装的用户，请按 [HarmonyOS NEXT 自行构建与安装指南](HARMONY_SELF_BUILD.zh-CN.md)操作：安装 DevEco Studio、登录已实名认证的个人开发者账号，为自己的设备生成调试签名并运行。

### Web

开发者本地运行：

```powershell
npm install
npm run serve:web
```

浏览器打开 `http://127.0.0.1:8087`。不要用普通静态文件服务器，因为 Web 端 LLM 请求需要项目自带的同源代理。

## 3. 病程日历

导航：**病程**。

### 新建病程

1. 点击右上角“+”。
2. 选择事件类型：手术、住院、化疗、放疗、维持治疗、靶向、免疫、用药、检查、身体指标或日记等。
3. 填写日期、医院、科室和备注。
4. 治疗事件可选择治疗方案，按周期批量生成多个治疗日。
5. 保存后事件会显示在月历和当天列表中。

![新建病程截图占位](images/screenshot-placeholder.svg)
> 截图占位 2：月历与新建病程表单。

### 按方案创建治疗事件

导航：**方案** → 新建/编辑方案。

- 支持化疗、放疗、维持、靶向、免疫等方案类型；
- 可配置周期长度、治疗日、药物、剂量、单位和给药途径；
- 放疗方案填写治疗部位和单次 Gy 剂量；
- 创建病程时选择方案和 Day 1，可批量生成后续治疗日；
- 生成后的单条事件仍可按实际执行情况修改。

> 截图占位 3：方案中的每日药物、剂量和给药途径。

## 4. 检查报告与 OCR

导航：**检查** → **导入报告**。

支持：

- 拍照导入；
- 选择图片或 PDF；
- Android 文件夹批量导入；
- OCR 队列后台处理、失败重试和批量清理。

识别成功后，报告会生成检查记录，包括：报告类型、采样日期、医院、结构化指标、异常标记和原始素材。

![导入报告截图占位](images/screenshot-placeholder.svg)
> 截图占位 4：拍照、选择文件和 OCR 队列。

### 隐私注意

- 未开启本地脱敏时，图片可能发送到你配置的 LLM 服务商；
- 开启 PaddleOCR 本地脱敏后，应用会先提取文字并尝试删除姓名、身份证号、住院号和电话等；
- 自动脱敏可能有遗漏，重要材料必须人工复核；
- PDF 文字版会优先在本地提取文字。

## 5. 检查记录

导航：**检查**。

- 按报告类型和日期筛选；
- 查看原始图片/PDF 和指标表格；
- 编辑医院、日期、指标和异常状态；
- 将检查记录关联到病程事件；
- 使用 SHA-256 和视觉指纹减少重复素材。

## 6. 指标图表

导航：**图表**。

### 日期趋势

- 选择一个或多个数值指标；
- 查看随日期变化的折线；
- 可显示治疗事件标记；
- 可收藏常用图表并排序。

### 化疗周期对齐

- 先在病程中创建带 Day 1 的治疗周期；
- 图表将多个周期按 Day 1 对齐；
- 便于比较不同周期同一天数的指标变化。

## 7. 报销材料

导航：**报销**。

1. 选择相关治疗事件创建报销计划。
2. 选择医保、商保、自费等类型。
3. 按材料清单上传报告、发票等附件。
4. 标记完成状态。
5. 可批量选择计划并导出 ZIP。

## 8. 智能识别服务

导航：**设置** → **智能识别服务**。

1. 选择 Azure OpenAI、OpenAI、DeepSeek、Kimi、豆包、Qwen、Gemini、MiniMax、GLM、OpenRouter 或自定义 OpenAI-compatible 服务。
2. 填写 API Key、API 地址和模型。
3. 使用“测试连接”确认配置。
4. 需要时开启 PaddleOCR 本地脱敏。

API Key 只保存在当前设备，不参与局域网同步或备份迁移。

## 9. 局域网同步

导航：**设置** → **局域网同步**。

1. 两台设备连接同一 Wi-Fi。
2. 两边都开启局域网同步。
3. 点击发现的设备，应用会自动计算同步预览。
4. 查看“本机将发生”和“对方将发生”的变化。
5. 可取消某一类别，跳过该类别的本次同步。
6. 确认后依次执行数据交换、数据库合并、素材分块传输和目录整理。

同步完成后会显示变化条数、发送/接收素材数量和耗时。

![同步预览截图占位](images/screenshot-placeholder.svg)
> 截图占位 9：双向变化预览与类别勾选。

注意：

- LLM 配置和 OCR 队列不会同步；
- 当前局域网同步不经过开发者服务器，但应用层不额外加密，请只在可信 Wi-Fi 下使用；
- 设备没有账号认证，请只选择认识的设备；
- 公共 Wi-Fi 或开启客户端隔离的网络可能无法发现设备；
- 素材传输中断后，下次同步会自动补齐未完成部分。

## 10. 备份、恢复与数据清理

- 备份使用 AES-GCM 加密，密码至少 8 位；
- 请妥善保存备份密码，忘记后无法恢复；
- LLM API Key 不进入可移植备份；
- 全局素材去重基于内容哈希和视觉指纹，建议操作前先备份；
- 彻底清除数据可在系统设置中清除应用数据或卸载应用。

## 11. 常见问题

### 为什么 OCR 停止了？

页面切换不会停止队列，但系统终止应用或浏览器标签后会暂停；重新打开应用后继续。

### 为什么发现不到另一台设备？

确认两端在同一 Wi-Fi、都已开启同步，且路由器没有开启 AP/客户端隔离。

### 为什么覆盖安装失败？

Android 新版本必须使用与旧版本相同的 release keystore。官方 Release 脚本会自动从 Azure 获取并校验固定签名。

### 数据是否会上传到开发者服务器？

不会。应用没有账号、广告或开发者运营的云端病历服务。只有你主动执行 OCR 或局域网同步时，数据才按你选择的服务流转。
